# WebEngine "6.12" 发布状态核实

- 核实日期：2026-10-09
- 起因：净室打包发现 6.12.0 submodules 无 qtwebengine；需确认独立产品是否已发布、在哪获取
- 支撑：总体方案 R3 / 阶段1 §4.10 / 打包记录 §2

## 结论

1. **不存在 "WebEngine 6.12" 这个版本**。Qt 6.12.0 release note 原文（Removed modules 节）：
   > "Compared to 6.11.x series 6.12 release does not ship with qtwebengine nor qtpdf ... as these are going to be released separately from now on."

2. **独立产品首个版本是 Qt WebEngine 6.140.0**（版本号跟随 Chromium：复用 6.11 所基于的 Chromium 140），包含全部 WebEngine 模块、Qt Pdf 模块、以及 qtwebview 的 webengine 后端。官方博客（Allan Sandfeld Jensen，2026-09-24）称其与 Qt 6.12.0 "前后"发布；动机是安全补丁提速与 EU CRA 合规。
   来源：https://www.qt.io/blog/qt-webengine-will-release-separate

3. **截至 2026-10-09，6.140.0 正式版尚未落地，处于 RC 阶段**。code.qt.io 的 qt/qtwebengine 仓库 tags 实测：
   - `v6.140.0-rc`（约 2026-09-30，Antti Kokko 打 tag）
   - `v6.140.0-beta2`、`v6.140.0-beta1`（约 3 周前）
   - **无正式 `v6.140.0` tag**
   来源：https://code.qt.io/cgit/qt/qtwebengine.git/refs/tags

4. **download.qt.io 无独立发布目录**：`official_releases/` 顶层无 qtwebengine 产品线；`qt/6.12/6.12.0/submodules/` 共 41 个模块 tarball，确认无 qtwebengine/qtpdf。正式发布后的下载通道待观察（新目录或在线安装器组件）。

## 对升级工作的影响

| 项 | 更新 |
|---|---|
| 获取路径 | 盯 code.qt.io 的 `v6.140.0` 正式 tag 即"已发布"信号；**现在就可拉 `v6.140.0-rc` 源码 + 复用 qt6-webengine 6.11 打包目录先行试打包**（打包记录流程可直接套用） |
| 兼容性 | 官方明确：WebEngine 仍可对旧版 Qt 构建，**构建时的 Qt 版本 = 最低运行时 Qt 版本** → 6.140.0 对着 Qt 6.12 构建即可 |
| 新构建要求预警 | 官方博客：年内后续版本将升级 Chromium 基线，**最低编译器要求提升且需要 Rust** → 打包基础设施需提前准备 Rust 工具链 |
| 3 个 deb 侧 WebEngine 应用 | "无 6.12 路径"的窗口期比预期短：rc 已在，正式版在途；风险从"渠道不明"降为"等待正式 tag（或用 rc 先行）" |

## 复现命令

```bash
# tag 状态
git ls-remote --tags https://code.qt.io/qt/qtwebengine.git 'v6.140*'
# 或访问 https://code.qt.io/cgit/qt/qtwebengine.git/refs/tags
```
