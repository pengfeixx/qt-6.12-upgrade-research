## 1. 整合口径

- **实体** = 本机已装的非 Qt 消费者包 ∪ linuxdeepin 有 Qt6 构建依赖的仓库（仓库名映射为包名后去重）
- **来源**：`两者`（本机有对应包且源码在 linuxdeepin，55）/ `本机`（仅本机出现，134）/ `仅GitHub`（本机没装但源码在组织内，27）
- **风险标记**（=1 命中，`-` 表示仅源码面、无本机运行时数据）：
  - 私有API：本机二进制 Depends `qt6-*-private-abi` **或** 源码 Build-Depends `qt6-base-private-dev`
  - QML：运行时依赖 libqt6qml/quick/qml6-module **或** Build-Depends `qt6-declarative-dev`
  - WebEngine / Multimedia / Wayland私有头：同理（运行时 或 `qt6-webengine-dev` / `qt6-multimedia-dev` / `qt6-wayland-private-dev`）
  - Network / Widgets：仅本机运行时口径（GitHub-only 实体标 `-`）
- 一致性校验：本机 134+55=189 ✓；GitHub 55+27=82 ✓

## 5. 口径与已知误差

1. Network/Widgets 仅统计本机运行时依赖；仅 GitHub 的 27 个实体无此项数据（标 `-`），实际 QML/Widgets 面只会更大。
2. `libqapt-qt6`（GitHub 仓库）映射自 KDE qapt 打包，本机对应包为 libqapt3-qt6，二者在清单中并存（差 1 个计数误差）。
3. `deepin-kwin`（fork 仓库）映射到本机 kwin-wayland 计为"两者"；kwin-common/kwin-x11 计为"仅本机"，属同一上游线的拆分计数。
4. 分类规则基于名称模式 + 人工校对一轮（libddm、linglong 工具链、udcp/usec 系列已归位）；个别边缘项目（如 libqtermwidget6-2）归类为"第三方上游生态"可能有一档之差，不影响风险标记。
